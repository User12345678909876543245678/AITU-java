Привет! Это мой небольшой проект — простая консольная утилита для работы с базой данных. Я написал её, чтобы не лезть каждый раз в SQL-запросы или тяжелые админки, когда нужно быстро поправить данные или что-то проверить прямо из терминала.

Зачем это нужно?
В основном я использую это для учета предметов: закинуть новую позицию, быстро глянуть, сколько что стоит, или вытащить инфу по конкретной вещи. Всё работает максимально просто: запустил, ввел команду, получил результат.

Что она умеет:
Добавлять шмотки: Быстро регистрирует новые предметы в БД.

Смотреть цены: Удобно, когда надо мгновенно чекнуть прайс.

Чекать инфу: Выводит всё, что известно о предмете из базы.

Минимализм: Никаких лишних кнопок, только терминал.

Как запустить у себя
Для начала склонируй репозиторий:

Bash
git clone [https://github.com/ваш-логин/название-проекта.git](https://github.com/User12345678909876543245678/AITU-java)
Затем просто запусти главный файл (убедись, что у тебя установлены все зависимости, если они есть):

Bash
python main.py  # или другой язык, на котором написан проект
Как пользоваться
Интерфейс текстовый, так что просто следуй подсказкам в консоли. Обычно это выглядит так:

Выбираешь действие (например, "Узнать цену").

Вводишь название предмета.

Получаешь данные из базы.
